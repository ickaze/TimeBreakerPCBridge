Component versions declared above come from the pinned package inputs and
CPython's own externals/SBOM documents. BUILD_MANIFEST.json additionally records
actual PE file version fields, hashes and tested libusb version in each release.
If the source inputs or Python release change, update their notices first.

Not bundled in the new application executable or runtime folder:
- libusb0.dll / libusb-win32.
- ViGEmBus MSI installers, including old 1.17.333.0 installers from vgamepad.
- x86 ViGEmClient.dll.
- setuptools, pkg_resources, pip, wheel and setuptools' vendored runtime metadata.
  Some are build-only tools, present in the build venv but excluded from release.

Downloaded separately by the setup GUI, not redistributed with this app:
- Zadig 2.9 (GPL-3.0-or-later) from its official GitHub release, signature checked.
- ViGEmBus 1.22.0 (BSD-3-Clause, end-of-life) from its official GitHub release,
  signature checked. The ViGEmBus license is included for reference; this does
  not mean a ViGEmBus installer or driver is bundled.
