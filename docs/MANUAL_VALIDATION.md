# 公開前の実機確認

Windowsの自動ビルド・スモークテストが成功しても、この確認は別途必要です。

1. ドライバーを未導入のWindows PCで、展開したEXEを起動する。状態確認の取得できる項目・警告・ログ保存を確認する。
2. 対象ドングルのハードウェアIDを照合し、GUI経由で公式Zadigを取得・署名確認・起動する。対象だけにWinUSBを導入する。
3. USB再接続と入力表示、単発トリガー、A/B/START/SELECTを確認する。
4. 四隅校正が各トリガー押下で1点だけ確定することを確認する。
5. マウス出力とF9停止、切断時の解放、画面外のマウス抑止を確認する。
6. 公式ViGEmBus導入後にXInputを有効化し、joy.cplで入力、画面外でもボタンが反応する標準設定を確認する。
7. ガン本体単発モードでPC連射の周期、押下時間、開始遅延を確認する。
8. 日英切り替え、次回起動への保存、読み取り専用場所でのログ保存フォールバックを確認する。
9. ドライバー削除は他アプリの利用状況を確認した専用検証環境で行う。対象・共有パッケージの拒否、処理ログ、再起動後の再導入を確認する。
10. テストしたOS、機器、ドライバー版、結果を記録し、Draft Releaseの説明へ追記してから公開する。

このファイルは実機検証の手順です。実施済みの結果を記載したものではありません。
