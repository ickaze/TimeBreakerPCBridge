Windows 10/11 · VID 0B9A / PID 016A

TimeBreaker PC Bridge v0.2.2
導入・操作・トラブルシューティング

Time Breakerの照準をマウス、ボタンを仮想Xbox 360コントローラーへ変換するPC用ツール。

English manual最初に導入画面Zadig・WinUSBXInput導入校正出力設定連射問題の切り分けまとめて削除EXEとBATの違い公式資料

1. 最初に：用意するものと最短手順

ガン、PS2用USBドングル、通電したセンサーバー、Windows PCを用意します。PS2映像や同期信号はこのツールでは必要ありません。ただし、ドングルから有効なX・Y座標が受信される必要があります。ガンは単発モードにしてください。

実行版はPythonの追加導入不要。配布ZIPをすべて展開し、TimeBreakerPCBridge.exeを直接起動してください。通常のフォルダー版では_internalを一緒に保持します。配布はフォルダー版です。EXEと_internalを含むフォルダー全体を保持してください。
  1. ZIPを「ドキュメント」など書き込み可能な場所へ展開し、EXEを起動します。ZIP内から直接実行しないでください。
  2. 主画面から「導入状況・インストール・アンインストール / HTML説明書」を開き、「状態を再確認」を押します。閉じた場合は、主画面下部の「導入状況・インストール・アンインストール / HTML説明書」から再表示できます。
  3. ドングル用WinUSBが未導入ならZadigで導入します。XInputを使うならViGEmBusも導入します。
  4. 「USB再接続（導入後に押す）」を押し、主画面の「接続済み」と照準座標を確認します。
  5. 四隅をトリガーで校正し、「出力設定ウィンドウを表示」でマウス／XInput出力と割り当てを設定します。
  6. F8で出力を開始し、ゲームへ切り替えます。F9で緊急停止します。

起動時の出力は毎回OFFです。ドライバー変更、校正、測定、導入画面を開く操作では出力を停止します。本ツールのウィンドウが最前面の間もゲーム用出力を抑止します。

表示言語とエラーログ（v0.2.2）

初回起動はWindowsの表示言語が日本語なら日本語、それ以外なら英語で表示します。主画面上部の「Language / 言語」で日本語とEnglishを切り替えられます。既に開いている出力設定・導入画面も更新します。選択はlanguage.jsonに保存し、次回からその選択を優先します。WindowsのUAC、Zadig等の外部アプリやOSが返すエラーメッセージは、それぞれの言語設定に従います。

状態確認はWin32_PnPSignedDriverへの依存を外し、Get-PnpDevice / Get-PnpDevicePropertyから取得します。取得できない項目があっても他の情報は表示します。例外、USBエラー、GUI操作のエラー、状態確認の警告をdiagnostics/error_日時.txtに保存し、最新内容はerror_latest.txtにも保存します。PowerShellの失敗時は終了コード、実行スクリプト、標準出力・標準エラーを記録します。画面の「エラーログの場所を開く」からフォルダーを開き、報告時は該当ファイルを添付してください。

EXEのフォルダーに書き込めない場合は%LOCALAPPDATA%/TimeBreakerPCBridge/diagnosticsへ保存します。ログにはデバイス情報やローカルパスが含まれることがあるため、報告前に内容を確認できます。同一エラーの短時間の繰り返しはログ生成を抑制します。スクリーンショットに出ていた0x80041010（無効なクラス）に対して、WMIのリセット等は実行しません。

導入状況は自動表示・自動診断しません。必要なときにウィンドウを開き、「状態を再確認」を押してください。USB再接続操作でも診断は自動実行しません。HTML説明書は現在の表示言語に応じて日本語／英語を開きます。

3. Zadigから対象ドングルへWinUSBを導入

Zadig自体は通常のインストール作業を必要としない実行形式です。Zadigでドングル用のドライバーをインストールする操作を行います。

  1. 導入画面の「Zadigを取得して起動」を押します。公式GitHubから取得して発行者署名（Akeo Consulting）を確認した後、WindowsのUACを表示して起動します。既に公式EXEがある場合は「保存済インストーラーを選択」から指定できます。
  2. ZadigでOptions → List All DevicesをONにします。
  3. 上部リストから対象ドングルを選び、USB IDが0B9A : 016Aであることを確認します。「Unknown Device」「不明なデバイス」等の表示名やPort番号だけでは選ばないでください。
  4. 右側ドライバー欄にWinUSBを選びます。libusbKやlibusb-win32は今回の標準手順では選びません。
  5. Install DriverまたはReplace Driverを押し、成功表示まで待ちます。
  6. Zadigを閉じ、ツールの「USB再接続」を押します。必要ならドングルを抜き差しします。
  7. 「状態を再確認」で対象のService=WinUSBとProblem=0、主画面の「接続済み」を確認します。
キーボード、マウス、USBハブなど別の機器は選ばないでください。対象を特定できない場合はドングルの抜き差しでリストの変化を確認し、ハードウェアIDを照合してください。既に対象がWinUSBで正常動作している場合は置き換え不要です。

ツールからZadigを起動する前にUSB読取を停止します。インストーラーを閉じただけでは受信を自動再開しないため、必ず「USB再接続」を押してください。ZadigでID確認とInstallを押す部分は、誤ったデバイスを変更しないようZadigの画面で操作します。

4. XInput用ViGEmBusの導入と確認

マウスだけを使う場合はこの手順を省略できます。実行版にはvgamepadのライブラリーが含まれますが、ViGEmBusのOSへの導入は別作業です。

  1. 「ViGEmBusを取得して導入」を押します。公式1.22.0のインストーラーを取得し、有効なNefarius発行者署名を確認して起動します。
  2. UACとインストーラーの画面に従って導入します。再起動を求められた場合はWindowsを再起動してください。
  3. ツールを起動し直して「状態を再確認」を押します。
  4. 「出力設定ウィンドウを表示」で「仮想Xbox 360 / XInput出力」をONにし、F8で出力を開始します。
  5. 導入画面を再度開くと出力は停止するので、確認用のjoy.cplを先に開き、設定をONにしたままF8で開始してjoy.cplへ切り替えます。仮想Xbox 360コントローラーのプロパティでボタンを確認します。
ViGEmBusは開発終了した共有ドライバーです。DS4Windows等でも利用されます。削除するとそれらの仮想コントローラー機能にも影響します。本ツールは他アプリの利用状況を自動判断できません。

「保存済インストーラーを選択」は公式Zadig／ViGEmBusのEXEに対応します。発行者の有効な署名を確認できないEXEは実行しません。ネット接続や署名確認に失敗した場合は、公式配布元とWindowsの署名情報を確認してください。非公式な再配布サイトからの導入はこの手順に含みません。

5. 四隅校正：トリガーで座標を確定

  1. センサーバーを主画面の位置に合わせて設置し、照準ウィンドウを主画面内に置きます。黄色ターゲットが画面外やタスクバーに隠れないようにします。
  2. ガン本体を単発モードにし、「① キャリブレーション開始」を押します。
  3. トリガーを一度離し、左上の黄色ターゲットを狙って1回引きます。押した瞬間のUSB受信座標が確定します。従来の「表示ターゲットの座標を確定」ボタンは表示しません。
  4. トリガーを離し、右上→右下→左下の順に同じ操作を行います。長押しでは次の点を連続確定しません。ターゲットに合わせる途中で引かないでください。
  5. 四隅完了で設定を保存します。画面内の照準表示が狙いに合っているか確認します。

校正開始時に既に押されているトリガーは確定に使いません。必ず一度離してください。照準未取得（X=0）では確定できず、座標差が不足すると校正を解除します。XまたはYが固定なら、センサーバーの距離・配置やガンの向きを調整してからやり直します。

マウス出力は校正時のターゲットの実際のデスクトップ位置から換算します。主画面の解像度、センサーバーの位置、射撃距離を変えたら再校正してください。ガン本体やPS2用設定は変更しません。複数モニター全体への出力には対応せず、主画面を使用します。

7. PC側連射の設定

ガン本体は単発モードにしてください。本体の連射によってUSB上のトリガーが途中でOFFになると、本ツールは実際の解放と区別できず、連射開始時刻をリセットします。

設定範囲・例
PC側トリガー連射OFFなら長押し状態をそのまま保持。ONで設定したON/OFFを生成します。
連射周期32～5000ms。100ms＝約10発/秒、50ms＝約20発/秒。
押下時間16ms以上、周期−16ms以下。周期100ms／押下40msなら40ms ON、60ms OFF。
連射開始遅延0～10000ms。押し始めから最初のONまでの待ち時間。

マウスとXInputのトリガー割当に共通適用します。画面外XInputモードでは照準未取得中もXInput連射を継続できます。Windowsのスケジューリングと受信／GUI更新間隔に依存し、設定値の厳密な実時間保証はありません。ガンのボタン組み合わせによる設定変更はありません。

9. GUIからまとめてアンインストール／クリーン導入のデバッグ

  1. 本ツール以外のUSB測定アプリ、DS4Windows等のViGEmBus利用アプリを終了します。
  2. 導入画面の削除欄で、ドングル用OEMドライバーと必要ならViGEmBusを選択します。ViGEmBusは共有利用に配慮して初期選択OFFです。
  3. 「選択したドライバー類をまとめてアンインストール」を押し、表示される対象を確認して続行します。USB読取と仮想パッドを停止します。
  4. UACを許可します。管理者処理は対象を再検出し、ViGEmBusの正規アンインストーラー／MSI、PnPUtilによる対象OEM INF削除とデバイス登録削除を実行します。
  5. ログが表示されるまでツールを閉じないでください。RESULT: COMPLETEDでも再起動・再確認が必要です。PARTIAL/FAILEDなら残存内容と終了コードを確認します。
  6. Windowsを再起動し、ドングルを再接続して「状態を再確認」。対象のWinUSB用OEMパッケージが残っていないか、ViGEmBusがMissingかを確認します。
  7. ドングルがコード28等の未導入状態になったら、Zadig→WinUSB→USB再接続→必要ならViGEmBus→ボタン確認→校正→出力設定の順で再導入します。

削除は0B9A:016Aおよび選択したViGEmBusに対応する外部OEMパッケージだけに限定します。切断済み／ドライバーストア内の該当INFもハードウェアIDから検索します。別デバイスで使用しているパッケージは拒否し、強制削除は行いません。利用中などで削除に失敗した場合は再起動後に再実行します。

「クリーン」は本ツールが使うドライバーの再導入を検証できる状態を意味します。Windows内蔵WinUSB、他機器のドライバー、Zadigの署名用証明書、Python環境、ダウンロード済みEXE、設定・ログは削除しません。履歴まで完全消去する機能ではありません。

旧設定なしで校正・設定初期値も確認したい場合は、ツールを終了しsettings.jsonを別名へ退避してから起動します。ViGEmBusのアプリ登録が削除できない場合は「Windowsのインストール済アプリ」から正規アンインストールを行い、その後再確認します。Windows更新で自動的にドライバーが戻った場合も診断表示を確認してください。

10. EXE、setup_windows.bat、start_windows.batの違い

v0.2.2はソースキットです。過去のEXEの再構成は行いません。正式Windowsビルド後のフォルダー配布はPython不要ですが、このアーカイブにEXEは入っていません。

11. 検証範囲と制約

パケット解析、連射、校正座標変換、マウス押下状態、トリガー校正の押下エッジ、画面外XInputとマウスの独立制御、削除対象の限定について自動テストを実施しています。配布用実行版はWindows x64 Python 3.13.16と固定した依存関係を用いてソースから正式ビルドします。実機USBやドライバー導入・削除の検証状況はdocs/SOURCE_VALIDATION.jsonと実機検証記録を確認してください。まずゲーム外で入力表示、F9停止、診断画面を確認してください。

受信仕様は6バイト以上、先頭2バイトがactive-lowボタン、次の2バイトがX、その次の2バイトがY（little-endian）です。USBドングルやガンのファームウェア更新、PS2実機の連射修正は行いません。XInputの振動、照準のアナログスティック出力、専用の画面外リロード方式には対応していません。
